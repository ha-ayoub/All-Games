<h2 id="fr">🇫🇷 Version Française</h2>
Arcadia est une plateforme web moderne regroupant une collection de jeux classiques revisités. Conçue avec une attention particulière portée à l'expérience utilisateur, Arcadia offre une interface élégante, intuitive et entièrement responsive.

Ce projet n'est pas simplement une collection de mini-jeux, c'est une expérience web soignée pensée pour être accessible et agréable à tous, que vous soyez sur mobile, tablette ou desktop.

## ✨ Fonctionnalités

- 🎯 **Collection de jeux classiques** : Tic Tac Toe, Pendu, Memory, Sudoku, Pierre-Papier-Ciseaux
- 🌍 **Multilingue** : Support de 8 langues (Français, Anglais, Espagnol, Arabe, Portugais, Allemand, Japonais, Coréen)
- 🌓 **Thème clair/sombre** : Basculez entre les modes selon vos préférences
- 📱 **Entièrement responsive** : Interface optimisée pour tous les écrans
- 🎨 **Design moderne** : Interface élégante avec animations fluides
- ⚡ **Performance optimisée** : Expérience de jeu rapide et fluide
- 🎮 **Navigation intuitive** : Menu latéral et recherche de jeux

## 🎲 Jeux Disponibles

### 1. **Tic Tac Toe**
Jeu de stratégie classique pour deux joueurs. Alignez trois symboles pour remporter la victoire.

### 2. **Hangman** (Pendu)
Devinez le mot mystère lettre par lettre avant que le temps ne soit écoulé.

### 3. **Memory Card** (Jeu de mémoire)
Testez et améliorez votre mémoire en retrouvant les paires de cartes identiques.

### 4. **Sudoku**
Résolvez cette grille de logique en remplissant les cases avec les bons chiffres.

### 5. **Rock Paper Scissors** (Pierre-Papier-Ciseaux)
Battez l'ordinateur en choisissant la meilleure option.

<h2 id="en">🇬🇧 English Version</h2>

**Arcadia** is a modern web platform featuring a collection of reimagined classic games. Designed with special attention to user experience, Arcadia offers an elegant, intuitive, and fully responsive interface.

This project is not simply a collection of mini-games; it's a carefully crafted web experience designed to be accessible and enjoyable for everyone, whether on mobile, tablet, or desktop.

## ✨ Features

- 🎯 **Classic game collection**: Tic Tac Toe, Hangman, Memory, Sudoku, Rock-Paper-Scissors
- 🌍 **Multilingual**: Support for 8 languages (French, English, Spanish, Arabic, Portuguese, German, Japanese, Korean)
- 🌓 **Light/Dark theme**: Switch between modes according to your preferences
- 📱 **Fully responsive**: Interface optimized for all screens
- 🎨 **Modern design**: Elegant interface with smooth animations
- ⚡ **Optimized performance**: Fast and fluid gaming experience
- 🎮 **Intuitive navigation**: Sidebar menu and game search

## 🎲 Available Games

### 1. **Tic Tac Toe**
Classic strategy game for two players. Align three symbols to win.

### 2. **Hangman**
Guess the mystery word letter by letter before time runs out.

### 3. **Memory Card**
Test and improve your memory by finding matching pairs of cards.

### 4. **Sudoku**
Solve this logic grid by filling in the cells with the correct numbers.

### 5. **Rock Paper Scissors**
Beat the computer by choosing the best option.
